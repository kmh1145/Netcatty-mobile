# 移动端 AI 助手（第一阶段）

## 使用方式

- 原有设置中的 API 地址、密钥和模型列表继续作为“默认配置”使用。
- 设置 → 管理多个 AI 服务商：可添加独立的地址、密钥、模型列表和兼容参数；无鉴权本地接口可不填密钥。目前接入协议为 OpenAI Chat Completions 兼容协议，不是 Anthropic / Gemini 原生协议。
- 对话顶部更多菜单可切换服务商、调整本次对话隐私、预览和编辑待发送的终端上下文。切换服务商前会提醒现有历史也将发送给新服务商。
- 支持流式回复和停止；未完整收到的回复不会生成可执行命令按钮。没有流式响应的兼容接口仍可显示完整回复。
- 执行命令前确认目标和命令；执行结束显示 stdout、stderr 和退出码。选择“发送结果并分析”后会自动发起分析，选择“仅查看，不上传”不会把结果加入模型历史。每条后续命令仍须用户确认，不是无人值守自动执行。

## 执行边界

独立执行通道复用当前已经认证的 SSH 客户端，包括实际端口、代理和跳板机；不会另连默认 22 端口，也不会向正在使用的 shell / tmux 注入执行标记。它**不继承当前终端的工作目录、临时环境变量或 tmux pane 状态**。需要指定目录时使用明确的 `cd <目录> && ...`，需要交互的命令应复制到终端操作。

执行通道不分配 PTY，立即关闭 stdin；打开通道限时 15 秒，执行限时 60 秒。stdout/stderr 各保留至多 12000 字符，并标记截断。关闭执行通道不保证终止已派生或脱离会话的远程进程；停止/超时后不能假定服务器已回滚，也不自动重试命令。

直接粘贴会拒绝多行和控制字符，避免“只粘贴”意外执行。含脱敏占位符的建议命令必须人工核对，不能直接执行或粘贴。

## 隐私、历史和同步

- 近期终端输出仍由原有默认开关控制；对话中可临时调整。默认隐藏服务器身份并进行常见密钥脱敏。脱敏只是尽力识别，不能代替用户检查。
- 本机历史按服务器 ID 保存到安全存储，重新连接后可继续。关闭“在本机保存聊天历史”会删除该服务器已保存的记录；“新对话”清除消息和摘要。
- 保留近期消息，达到消息数/字符预算时请求模型总结旧内容，保留目标、已执行操作和未解决问题。摘要失败不会清空旧记录。预算采用保守字符阈值，不是各模型的精确 tokenizer；摘要也会产生一次 API 请求及费用。
- 新增服务商、选择状态和聊天历史使用 `netcatty.mobile.ai.workspace.*` 独立命名空间。**不进入保险库、不触发云同步、不覆盖桌面 AI 配置。**原有默认配置继续沿用既有保存/同步逻辑。
- 不提供无限历史归档；旧内容摘要后只保留摘要和近期消息。不要把聊天历史当作审计日志。

## 实现入口

| 文件 | 职责 |
| --- | --- |
| `lib/infrastructure/ai/ai_service.dart` | Chat Completions、SSE 分段解析、取消、超时、参数降级 |
| `lib/infrastructure/ai/ai_command_executor.dart` | 独立 SSH 执行通道、输出限额、取消和退出状态 |
| `lib/infrastructure/ai/ai_workspace.dart` | 本机服务商/历史序列化、串行安全存储、脱敏 |
| `lib/presentation/widgets/ai_chat_sheet.dart` | 对话、摘要、隐私预览、执行/上传确认 |
| `lib/presentation/widgets/ai_providers_page.dart` | 服务商新增、编辑、删除、拉取模型 |

聊天使用独立 HTTP 客户端，连接超时 15 秒，响应头/流无数据超时 120 秒，避免被云同步 HTTP 客户端较短的超时限制。默认不发送 temperature 或强制 JSON 参数；用户可对每个服务商控制 JSON 模式和 reasoning_effort。只有 400/422 明确指出可选参数不支持时降级重试一次；认证、限流、网络中断和命令执行均不自动重试。
