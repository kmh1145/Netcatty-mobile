# 移动端 AI 助手（第一阶段）

## 使用方式

- 设置 → 管理多个 AI 服务商：统一配置地址、密钥、模型列表和兼容参数。旧单服务商配置会一次性迁移，删除迁入的配置后不会再次恢复。
- 支持 OpenAI Chat Completions 兼容接口，无鉴权接口可不填密钥；不支持 Anthropic / Gemini 原生协议。模型列表默认一行，随输入增长。
- 首次打开需要确认风险提示；仅明确点击“了解了”后在本机记住，不在云端同步。
- 拖动聊天面板顶部可展开至全屏；模型、思考强度和终端输出上传开关位于输入框上方同一行。
- 更多菜单可切换服务商、调整隐私、预览和编辑终端上下文、读取终端并分析。切换服务商前提示现有历史也会发送给新服务商。
- 支持流式回复、停止、JSON/带说明的 JSON/命令数组/Shell Markdown 代码块识别。常见无语言代码块和明确标注的行内命令保守识别；配置代码和普通输出不作为命令。未完整接收的回复不会生成执行按钮。

## 执行与输出边界

命令通过打开助手时绑定的 **当前终端会话 ID** 发送，不再打开独立 SSH exec 通道，不另连默认 22 端口。沿用当前 shell/tmux 的目录和环境，输出留在该终端。

每次执行都需要确认完整命令和目标。当前终端可能正在运行交互程序或等待密码，应用无法可靠判断是否处于 shell 提示符；执行前必须人工检查。不会注入结束标记，不根据等待时长猜测完成，也不伪造退出码。AI 的“停止”只停止模型请求，不终止已发给终端的命令。

直接粘贴拒绝多行和控制字符，避免“只粘贴”意外执行。含脱敏占位符的命令必须人工核对，不能直接执行或粘贴。

通过“读取终端并分析”可以预览并确认发送当时的终端快照，无需手动复制。该快照可能包含其他命令的输出，不能证明执行完成。即使自动上传关闭，此操作也需要独立确认；取消则不发送。执行本身不会自动触发分析请求。

## 隐私、历史和同步

- 上传开关控制后续提问是否附带近期终端输出，修改会保存。不会撤回以前已共享的消息、历史或摘要。
- 默认隐藏服务器身份并进行常见密钥脱敏。脱敏只是尽力识别，不能代替用户检查。
- 历史按服务器 ID 保存在本机安全存储。关闭保存会删除该服务器已有历史；“新对话”清除消息和摘要。
- 达到消息数/字符预算时请求模型总结旧内容，保留近期消息。摘要失败不清空旧记录；摘要调用也会产生费用。不是无限归档，不要用作审计日志。
- 服务商、选择状态、历史、迁移标记和风险确认使用 `netcatty.mobile.ai.workspace.*`。**不进入保险库、不触发云同步、不覆盖桌面 AI 配置。**
- 保留旧领域模型与同步字段用于兼容，不再显示独立旧表单。迁移读取旧配置而不改写保险库。

## 实现入口

| 文件 | 职责 |
| --- | --- |
| `lib/infrastructure/ai/ai_service.dart` | Chat Completions、SSE、取消、超时、参数降级 |
| `lib/infrastructure/ai/ai_reply_parser.dart` | 完整回复中的结构化命令与 Markdown 命令提取 |
| `lib/infrastructure/ai/ai_workspace.dart` | 安全存储、迁移、风险确认、历史、脱敏 |
| `lib/presentation/widgets/ai_chat_sheet.dart` | 聊天、隐私、执行确认和快照分析 |
| `lib/presentation/widgets/ai_panel.dart` | 首次风险提示、面板拖动和键盘布局 |
| `lib/presentation/widgets/ai_providers_page.dart` | 服务商新增、编辑、删除和拉取模型 |
| `lib/presentation/screens/terminal_screen.dart` | 绑定当前终端、配置和历史加载 |

聊天使用独立 HTTP 客户端，连接超时 15 秒，响应头/流无数据超时 120 秒。默认不发送 temperature 或强制 JSON 参数；每个服务商可控制 JSON 模式和 reasoning_effort。只有 400/422 明确指出可选参数不支持时降级一次；认证、限流、网络中断和命令执行不自动重试。
